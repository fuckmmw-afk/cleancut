# CleanCut

iOS-приложение, которое на самом айфоне, без облаков и серверов, вырезает из сырого «говорящего» видео паузы и неудачные дубли и экспортирует готовый ролик.

Интернет нужен один раз: чтобы скачать модели в Настройки → Модели. Дальше всё работает офлайн, обработка видео в сеть не ходит.

- iOS 18.0 и новее, целевые устройства: iPhone 16 Pro и 17 Pro (8 ГБ RAM и больше).
- SwiftUI, Swift 6, проект генерируется XcodeGen из `project.yml`. `.xcodeproj` в репозитории нет.

## Как это работает

1. **Импорт.** Видео берётся из Фото (PHPicker, оригинал без перекодирования) или из Файлов и копируется в песочницу проекта. Файл никогда не читается в память целиком.
2. **Звук.** `AVAssetReader` → 16 кГц, моно, Float32 во временный файл.
3. **Паузы.** Silero VAD (Core ML) решает, где речь, а точная граница уточняется по громкости с шагом 20 мс. Если Silero не загрузился, работает запасной детектор по RMS.
4. **Транскрипция.** WhisperKit, язык `ru`, таймкоды по словам. Слова склеиваются во фразы по пунктуации и паузам.
5. **Повторы по словам.** Без всякой модели находятся заикания и рестарты внутри предложения («мы по… мы поговорим», «я я пошёл») и одинаковые предложения подряд. Во всех случаях остаётся последняя версия.
6. **Дубли по смыслу.** Whisper выгружается из памяти, после этого загружается локальная LLM (MLX Swift). Она видит весь транскрипт (длинный — окнами по 50 фраз с 30 фразами контекста до и 15 после) и отвечает строго по JSON-схеме `{"remove":[{"id":N,"kept":M,"reason":"retake|false_start|garbage"}]}`, где `kept` — более поздняя фраза, которая заменяет вырезаемую. Каждое решение проверяется по тексту: замена должна идти позже, стоять рядом и повторять слова дубля. Неподтверждённые предложения не вырезаются, а помечаются на ревью как «возможно дубль». Если схема недоступна, работает обычная генерация с проверкой JSON и двумя повторами.
6. **Ревью.** Транскрипт с зачёркнутыми и подсвеченными резами, плеер показывает результат сразу. Любой рез можно вернуть, любой кусок вырезать вручную.
7. **Экспорт.** Полное перекодирование в HEVC аппаратным кодером, резы по границам кадров, кроссфейд звука 16 мс на каждой склейке.

## Сборка через GitHub Actions

Локальный Mac не нужен.

1. Запушь изменения в `main` или запусти workflow **Build IPA** вручную (вкладка Actions → Build IPA → Run workflow).
2. Workflow на `macos-26`:
   - гоняет unit-тесты пакета `CutCore`;
   - генерирует проект через `xcodegen generate`;
   - собирает Release под `iphoneos` с `CODE_SIGNING_ALLOWED=NO`;
   - упаковывает `Payload/CleanCut.app` в `CleanCut-unsigned.ipa`.
3. Готовый файл лежит в артефактах запуска под именем **CleanCut-unsigned-ipa**. Лог сборки — в артефакте **xcodebuild-log**.

Скачать последний артефакт из терминала:

```bash
gh run download --name CleanCut-unsigned-ipa
```

Первая сборка идёт долго (компилируется MLX), следующие быстрее за счёт кэша пакетов.

### Локальная сборка (если есть Mac с Xcode 26)

```bash
brew install xcodegen
xcodegen generate
open CleanCut.xcodeproj
```

Тесты ядра запускаются без Xcode:

```bash
cd Packages/CutCore && swift test
```

## Установка через ESign

IPA не подписан, подписывать нужно своим сертификатом.

1. Перекинь `CleanCut-unsigned.ipa` на айфон (AirDrop, Файлы, Telegram).
2. Открой файл в ESign: «Поделиться» → ESign, либо в ESign: Файлы → Импорт.
3. Нажми на IPA → **Подпись**, выбери свой сертификат и профиль → **Подписать**.
4. Установи подписанное приложение из вкладки «Приложения».

Замечания по подписи:

- **Bundle ID** можно менять, приложение к нему не привязано.
- **Entitlement `com.apple.developer.kernel.increased-memory-limit`** описан в проекте, но в неподписанный IPA не вшит. Если твой профиль его поддерживает, добавь его при подписи: с ним у большой LLM больше запас по памяти. Без него приложение тоже работает: если памяти для Qwen3-4B не хватает, оно само переключается на Qwen3-1.7B.
- **Фоновая обработка на iOS 26+** (`BGContinuedProcessingTask`) включается, только если bundle ID после подписи остался `app.cleancut.CleanCut`. Иначе приложение работает как на iOS 18: экран не гаснет, сворачивать нельзя.

## Модели

В IPA моделей нет. Их скачивают в приложении: Настройки → Модели. Там у каждой модели видно состояние и размер, её можно скачать, отменить загрузку или удалить. Кнопка «Скачать выбранные» качает то, что нужно для текущих настроек. Если модели не хватает, экран обработки предложит её скачать и начнёт работу сам, когда загрузка закончится. Модели лежат в `Application Support/Models` и в резервную копию iCloud не попадают.

| Назначение | Модель | Размер | Нужна, когда |
|---|---|---|---|
| Паузы | Silero VAD v6 (Core ML), `FluidInference/silero-vad-coreml` | ~1 МБ | всегда, если включён Silero |
| Речь, по умолчанию | Whisper large-v3-turbo, `argmaxinc/whisperkit-coreml` → `openai_whisper-large-v3-v20240930_626MB` | ~630 МБ | по умолчанию |
| Речь, полегче | Whisper small | ~490 МБ | если выбрана в настройках |
| Речь, самая лёгкая | Whisper base | ~150 МБ | если выбрана в настройках |
| Дубли, по умолчанию | `mlx-community/Qwen3-4B-Instruct-2507-4bit` | ~2.3 ГБ | по умолчанию |
| Дубли, запасная | `mlx-community/Qwen3-1.7B-4bit` | ~1 ГБ | если выбрана или не хватило памяти |

С настройками по умолчанию нужно около 3 ГБ на модели. Whisper дополнительно скачивает свой токенайзер (несколько МБ).

Почему large-v3-turbo в варианте на 626 МБ: это та же модель, но сжатая Argmax специально под iPhone. Полный вариант весит около 1.6 ГБ и на телефоне даёт ту же точность при большем расходе памяти.

Whisper после скачивания сразу компилируется под Neural Engine (это может занять пару минут) и скачивает свой токенайзер, поэтому при обработке видео он грузится за секунды и без сети.

## Настройки

- минимальная длина паузы для вырезания (по умолчанию 0.4 с);
- отступ перед речью (по умолчанию 120 мс) и тишина после фразы (по умолчанию 50 мс);
- Silero VAD или детектор по громкости;
- модель Whisper: large-v3-turbo / small / base;
- поиск дублей: Qwen3-4B / Qwen3-1.7B / простые правила без LLM / выключен;
- битрейт экспорта: 10 Мбит/с до 30 кадров/с и 16 Мбит/с для 50–60 кадров/с.

## Структура

```
project.yml                 описание проекта для XcodeGen
.github/workflows/build.yml тесты и сборка неподписанного IPA
Packages/CutCore/           чистая логика без зависимостей от iOS, с unit-тестами
  CutPlanner                слияние интервалов, отступы, огрызки, привязка к кадрам
  PhraseSegmenter           слова → фразы
  RetakeJSON, RetakePrompt  промпт, чанки, разбор и проверка JSON от LLM
  SpeechSegmenter, EnergyVAD речь по вероятностям Silero и по RMS
  HeuristicRetake           поиск дублей без LLM
App/
  Import/                   PHPicker, fileImporter, копирование в песочницу, проверка места
  AudioExtract/             AVAssetReader → 16 кГц моно Float32
  VAD/                      Silero VAD через FluidAudio, запасной RMS
  Transcription/            WhisperKit
  RetakeDetector/           протокол RetakeDetector и реализация на MLX
  Pipeline/                 этапы анализа, прогресс, отмена
  Review/                   экран ревью и плеер
  Export/                   композиция, экспорт в HEVC, сохранение в Фото
  Project/                  модель проекта и хранение
  Support/                  настройки, ошибки, нагрев, фоновая задача
  UI/                       главный экран, настройки, экран обработки
```

Чтобы сменить модель поиска дублей, достаточно реализовать протокол `RetakeDetector` и вернуть свою реализацию из `RetakeDetectorFactory`.

## Ограничения

- **Сворачивать приложение во время обработки нельзя.** LLM работает на GPU, а GPU в фоне на iOS недоступен. На iOS 26+ этапы звука, пауз и распознавания могут пережить сворачивание, поиск дублей ждёт возврата в приложение.
- **Dolby Vision.** HDR-видео экспортируется как HEVC Main10 с исходными цветовыми параметрами (HLG), но динамические метаданные Dolby Vision не переносятся.
- **Пространственный звук.** В ролик идёт обычная стерео- или монодорожка.
- **Маленькая LLM ошибается.** Поэтому экран ревью обязателен: каждое решение модели видно и отменяется одним тапом.
